# Security Policy

## Supported scope

This project is defensive tooling. It should remain read-only and should not require credentials to perform its normal local workflow.

## Reporting a vulnerability

Please use a private GitHub security advisory when available. Do not post secrets, tokens, private logs, customer data, or exploit details in a public issue.

## Non-goals

Credential harvesting, persistence, exploitation, destructive automation, and stealth behavior are outside the project scope.
